Source splices preserve unrelated fields, unknown settings, comments and line endings; ambiguous affected fields and imported repeated canonical sort keys remain Source-only. Filters, formulas, global display labels, summaries and presentation are outside this dialog; grouping retains its existing control.
- **Review existing nested strings:** literal before/after decoded strings and exact scalar YAML expose newline and trailing-newline changes, within the existing 4,096 UTF-16-unit string bound. **Review multiline text** offers **Lines (LF)** and **Escaped text (JSON string)**. Lines is read-only for decoded CR/CRLF until explicit Escaped text mode, which retains exact CR, LF and trailing newlines. Changed multiline Text requires review again after any draft/type change. Edited scalars use double-quoted YAML; this does not promise original block-scalar style. Existing visible Source handoff, source/version checks, Apply/Cancel and shared Undo remain.
- **Edit supported multiline flow collections:** reviewed Add/Remove/Move/Rename for proven line-separated flow maps/lists, including supported trailing commas and empty-after-removal containers. Exact source splices retain other entries and block-scalar siblings. Mixed inline/newline layouts, uneven separators and ambiguous comment/anchor ownership require Source editing.
- **Export local Canvas content:** literal export stays available. Explicit local-content inclusion captures supported existing Markdown note/heading/block text and static PNG/JPEG/WebP bytes. Review lists what is included or omitted and identifies live unsaved text. Output is a self-contained SVG/PNG with escaped literal text and embedded raster bytes. Model/selection/owner, saved Canvas and referenced versions/buffers are rechecked before download. Bounds include 64 file cards/32 sources, 262,144 note characters per source/524,288 total, 1 MiB per Markdown source, 2 MiB per raster/4 MiB total, 4,096 pixels per side/16 million pixels and 8 MiB output. Preparation, fresh source verification and PNG passes each have five-second deadlines; owned resources are released. Genuine cache-only read-only vaults use cached bytes without raw/API requests.
