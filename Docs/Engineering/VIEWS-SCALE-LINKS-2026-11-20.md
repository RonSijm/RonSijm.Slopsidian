## Delivered behavior

- **Manage base views:** explicit review and Apply and save for Add Table/List/Cards, Duplicate, Rename, Move earlier/later and Remove. New views start with an explicit file.name column. Duplicates retain their complete existing configuration, including unknown settings. CST source splices retain unrelated tokens, comments, BOM and line endings. Names must be unique after Unicode/case normalization; the 64-view limit, last-view and movement boundaries are enforced in handlers. Ambiguous layouts and alias ownership require source editing. Changed physical bytes/version/BOM, source/model/selection or owner/provider reject the review. No matching notes are edited. Renamed/removed view references remain explicit follow-up work.
- **Canvas viewport rendering:** 240px overscan; at most 384 detailed card shells, 96 rich bodies and 512 interactive connections. Dense overflow uses a fixed SVG overview rather than per-card DOM or a giant pixel surface. Full-model hit testing, selection, fit/jump, geometry, content and Undo branches are retained. Focus/inspector/gesture owners are prioritized. Unowned offscreen rich resources are retired, stale async results cannot revive them, and website previews require explicit consent again after retirement. Invalid/hidden initial viewports wait for a real resize. This improves bounded rendering, not unlimited-board or original-device performance parity.
- **Nested Properties links:** supported whole string wiki/Markdown links use the existing exact destination resolver and expose readable navigation to known notes, headings and blocks. Text drafts offer Find existing link using the existing note/alias/subpath suggestions; choosing only fills the draft with explicit wiki syntax and creates no note, heading or block. Apply retains exact source-span checks, visible Source handoff and shared Undo. Chosen destination, source/session/root/adapter, assigned type and link preferences are rechecked. Cached read-only navigation remains available and authoring refuses before mutation/Source allocation. Mixed prose, external/missing/ambiguous links and unsupported YAML remain literal or Source-only.
