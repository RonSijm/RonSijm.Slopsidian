## Reproduction and remaining scope

Use `node tools/integration-wave.mjs --plan` to inspect the matrix, then
`--run --validate`; `--resume=<receipt>` continues only the identical epoch.
The complete runtime matrix requires Windows GUI access and the pinned local
compatibility fixtures described by the linked feature guides. Ordinary builds
do not require the original installation or private reference folder.

The accepted wave is finite. Full native/private/visual/editor/plugin equivalence,
physical IME/microphone/quota behavior, broader OS/display/browser and codec
variants, manual damaged-shell recovery and already-active-worker atomic rollback
remain separate. Authorized Sync/Publish services, signed distribution,
publication and updates are not established by these local results.
