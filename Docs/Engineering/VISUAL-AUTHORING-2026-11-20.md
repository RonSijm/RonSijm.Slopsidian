## Limits and remaining work

Canvas choices inspect at most 10,000 loaded files, show at most 100 file results and preview Markdown of at most 262,144 characters. Existing board limits remain 5,000 cards, 20,000 connections and 100 Undo states. Image export/jump/convert, general resource scheduling/virtualization, additional formats, original pickers/device gestures/private APIs and exact visual parity remain open. Live external website loading is not newly accepted.

Graph keeps its existing 10,000-node, 100,000-link and three-second worker limits. Export uses at most 4,096 pixels per side, 16,000,000 total pixels and 8 MiB each for SVG/PNG; local PNG preparation has its own five-second deadline. System fonts/export colors and the 10:7 graph frame are explicit. Original physics/animation/pixels/private APIs and broader hardware/scale acceptance remain open.

New destinations support one absent Markdown file in an existing folder, 1–32 supported literal basename mentions and source notes up to 262,144 UTF-16 code units. Larger batches, new heading/block destinations, templates, arbitrary aliases and complete matching/Markdown syntax remain open. No Undo history across a restart is claimed.

The wider roadmap still includes additional Bases views/full APIs, broader Properties/YAML and recovery formats, physical audio-device/wider codec acceptance, Sync/Publish services, release/installation/update acceptance and original/private/visual equivalence. This targeted iteration does not renew the entire core/plugin/release matrix. [Remaining roadmap](../Project/ROADMAP.md).
