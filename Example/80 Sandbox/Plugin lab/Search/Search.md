## Exercise 1 · Compare a phrase with its context

Search the shared phrase, inspect excerpts and open each relevant note. The handover is operational detail; the briefing is the public explanation. Choose which belongs in a meeting link.

## Exercise 2 · Try spelling and naming variations

Search the alias, accent-free term and deliberate typo above. Omnisearch's existing `ignoreDiacritics` and fuzziness settings are preserved. Exact ranking is not prescribed: titles, headings, indexed context and user settings influence it.

## Exercise 3 · Search within the note you found

Open Telescope handover and run Omnisearch's in-file search command, then look for `eyepiece`. Compare the smaller result set with the vault-wide search. Use the plugin's available result-opening actions to keep the original note visible while opening a match in another pane.

## Exercise 4 · Keep old decisions discoverable

Inspect the Archive note's `status` and heading before reusing its text. If you choose to downrank the lab's Archive folder in Omnisearch settings, repeat the query and compare the ordering. Downranking changes relevance; it does not rewrite `status` or remove a file.
