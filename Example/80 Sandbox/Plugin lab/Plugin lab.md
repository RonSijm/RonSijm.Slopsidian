# Plugin lab

Prepared material for the plugins that previously had shorter demos. Each lab has something to use immediately and several actions with inspectable results. Begin with a writable copy; the original four project records and five project actions stay the baseline.

| Lab | Prepared material | Features to exercise |
| --- | --- | --- |
| [[80 Sandbox/Plugin lab/Decision register]] | Three custom admonition types, saved decisions, risks and experiments | Native and executable fenced forms, custom colors and icons, titles, collapse states and Markdown content; complete native visual parity remains open. |
| [[60 Visuals/Workshop room.excalidraw]] | A populated room plan with linked stations, labels and visitor route | Edit groups, follow note links, embed a drawing and export a view. |
| [[60 Visuals/Workshop delivery board]] | Four lanes, linked cards, tags and fixed dates | Drag cards, filter, edit dates and archive completed cards. |
| [[80 Sandbox/Plugin lab/Folder notes/Launch pack/Launch pack]] | A nested folder-note pack and two live overviews | Folder landing pages, depth/type filters, automatic overview refresh, rename synchronization. |
| [[80 Sandbox/Plugin lab/Navigation desk]] | Three named work routes and prepared homepage destinations | Homepage open modes, file/Canvas/Base destinations, Recent Files history and exclusions. |
| [[80 Sandbox/Plugin lab/Search/Search]] | Four related notes with aliases, accents and distinct terms | Phrase, alias, accent and fuzzy search; vault versus in-file search. |
| [[80 Sandbox/Plugin lab/Completion practice]] | A local JSON dictionary with descriptions, aliases, expansions and a cursor marker | Vocabulary, custom dictionary, snippet expansion and linked-note completion. |
| [[80 Sandbox/Plugin lab/Reading review]] | An annotated passage and clean practice version | A meaningful Highlightr palette, recoloring, removing a highlight and inspecting saved markup. |
| [[80 Sandbox/Plugin lab/Linter/Linter]] | Raw and cleaned versions of a briefing | Manual spacing cleanup, YAML array cleanup, table formatting and diff review. |
| [[80 Sandbox/Plugin lab/Note Refactor/Note Refactor]] | A multi-section draft, expected extracted notes and a destination folder | Selection extraction, splitting at the cursor, splitting by heading and transclusion. |
| [[80 Sandbox/Plugin lab/Date planning]] | A worksheet with absolute dates and relative phrases | Autosuggest, selected-text parsing, date/time insertion and daily-note navigation. |
| [[80 Sandbox/Plugin lab/Outliner/Run of show]] | A nested event outline and a target arrangement | Move subtrees, indent/outdent, fold, drag and multi-line list editing. |
| [[60 Visuals/Diagram workshop]] | Flowchart, state, sequence and Gantt examples plus workshop toolbar elements | Insert reusable Mermaid fragments, edit styles and maintain a diagram timeline. |
| [[80 Sandbox/Plugin lab/Git/Git]] | A portable repository bundle containing fictional commit history | Inspect history and blame, compare revisions, stage and unstage a practice edit locally. |

The six additional optional plugins remain additional installs. [[00 Start/Plugin demo coverage]] records which installed-plugin workflows have runtime evidence and which are prepared exercises awaiting a compatible host.
