# Navigation desk

Use these routes to exercise Homepage and Recent Files with the same work you are doing elsewhere in the vault. No visit history is pre-populated.

## Route A · Prepare the opening evening

Open these notes in order, then return here:

1. [[30 Projects/Project cockpit]]
2. [[60 Visuals/Workshop delivery board]]
3. [[80 Sandbox/Plugin lab/Search/Visitor briefing]]
4. [[30 Projects/Meetings/2026-10-21 Planning]]

Open Recent Files. Reopen the briefing from the list; use Ctrl/Cmd-click to keep your current tab while returning to a recent note. Your actual visits supply the ordering.

## Route B · Follow a research thread

1. [[70 Data/Library/Watching the night sky]]
2. [[80 Sandbox/Plugin lab/Reading review]]
3. [[80 Sandbox/Plugin lab/Note Refactor/Practice draft]]
4. [[70 Data/Flashcards]]

Return to the research note through Recent Files. Then search for its phrase through Omnisearch. One workflow uses your visit history, the other uses indexed content.

## Route C · Change the surface you start from

Homepage's prepared destination is [[30 Projects/Project cockpit]], with manual opening set to keep your other notes. Startup opening, opening when empty, automatic commands and automatic note creation are off.

Run **Homepage: Open homepage** with a research note already open. The cockpit should open or become active without closing that note. Use **Set current file as homepage** or the plugin's settings to try these existing alternatives:

- [[60 Visuals/Project constellation.canvas]] for a visual project map.
- [[70 Data/Projects.base]] for a native table.
- [[80 Sandbox/Plugin lab/Navigation desk]] for this work-route menu.

Restore the cockpit afterwards. Startup behavior is a separate preference; enabling it is optional.

## Keep navigation history useful

Recent Files can omit file paths using its settings. Try a temporary omission for `50 Templates` after opening a template, and compare it with an ordinary note. Remove that omission afterwards if you want the original behavior. Omitting a path affects the recent list; it does not delete or hide the note from the vault explorer.
