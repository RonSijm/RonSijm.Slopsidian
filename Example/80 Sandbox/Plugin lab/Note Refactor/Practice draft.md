# Opening evening research draft

This draft collects three different kinds of knowledge. Separate them with Note Refactor while preserving the links that explain their context.

## Welcome script

Ask the visitor what they would like to discover before explaining either station. Let the first observation come from the visitor, then offer a name or a short explanation.

The public-facing [[80 Sandbox/Plugin lab/Search/Visitor briefing]] supplies the wording; [[30 Projects/Community workshop]] is the source project.

## Equipment handover

### Telescope

Keep the eyepiece cap with the case. Place the chart beside the lantern. [[30 Projects/Observatory]] keeps the actual next-action checklist.

### Garden

Keep labels beside the seedlings. Ask the host about the courtyard before moving the station. [[30 Projects/Garden]] holds the source project information.

## Feedback loop

At closing, ask for one discovery and record one anonymous observation. Compare it with the experiment in [[80 Sandbox/Plugin lab/Decision register]] before rewriting the welcome script.
