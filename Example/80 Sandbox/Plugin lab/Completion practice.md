# Completion practice

Various Complements is configured with a **local** dictionary at `70 Data/Workshop dictionary.json`, vault vocabulary and internal-link aliases. It needs no downloaded dictionary or external service.

## Exercise 1 · Complete a domain word

On a new line type `spectro` or `constell`. Select the described dictionary entry and inspect the resulting word. The dictionary's descriptions distinguish a vocabulary suggestion from a note link.

Practice line:

## Exercise 2 · Expand a short phrase

Type `wswelcome` and choose **Workshop welcome**. It inserts a full welcome sentence even though the menu displays a short label. Try the alias `welcome-script` as a second way to reach that entry.

Practice line:

## Exercise 3 · Leave the cursor at the next decision

Type `wsdecision` and accept **Workshop decision**. The expansion contains a designated `¦` cursor marker. The plugin removes the marker and places the caret where you should type the decision before completing the reason.

Practice line:

## Exercise 4 · Insert a linked note by its alias

Begin an internal link and search for `Welcome script`. With alias suggestions enabled, select the Visitor briefing note. Inspect the saved wiki-link target and display label.

Completion offers text; it does not update a Resource's reading status or enforce a fileClass's allowed values. Undo the inserted text or use a copy to reset. Edit the local JSON dictionary only when you want to change the available vocabulary and expansions.
