# Run of show

Restructure this working outline in a copy. The target arrangement is [[80 Sandbox/Plugin lab/Outliner/Target arrangement]]; it keeps each station's instructions with its parent.

- Open the evening
  - Alex welcomes visitors
    - Ask what they would like to discover
    - Explain that both stations end with one observation
  - Point out the exit and welcome desk
- Telescope station
  - Set up the telescope
    - Put the eyepiece cap with its case
    - Place the printed chart beside the lantern
  - Invite an observation
    - Ask the visitor to describe a pattern
    - Offer the name after the description
  - Collect a question for the closing conversation
- Garden station
  - Sam introduces the seedling
    - Compare the seedling with its picture
    - Invite one guess about its next change
  - Offer a label to take away
- Close the evening
  - Ask each visitor for one discovery
  - Capture one follow-up for the next workshop

## Exercise 1 · Move an entire station

Place the cursor in Garden station and use **Outliner: Move list and sublists up**. Its children and grandchildren should travel with it. Compare with the target arrangement.

## Exercise 2 · Change responsibility without losing text

Outdent Collect a question so it becomes a top-level preparation step, then indent it under Close the evening. Compare the Markdown indentation before and after. Undo both operations to recover the source.

## Exercise 3 · Edit and fold a subtree

Fold the station's setup list, unfold it, and add a sibling with Enter. Try moving the child with the keyboard and, where supported, dragging its bullet. Keep the distinction between a visual fold and a change to stored indentation.

## Exercise 4 · Review a concise outline

Fold both station parents to leave only the event stages visible. Use that view as an agenda, then unfold the station you are rehearsing. The structure remains ordinary Markdown; there is no automatic task scheduling or Kanban synchronization.
