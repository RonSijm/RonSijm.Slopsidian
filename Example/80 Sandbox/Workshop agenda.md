# Workshop agenda

A real outline to rearrange with Outliner. Fold a parent, move it with its children, and indent or outdent one station. Commands change the Markdown list hierarchy.

## Preparation dates

In a copy, type `@next Friday` or select `in two weeks` and run Natural Language Dates' parse command. The inserted date is resolved when you run it; it does not keep moving with the calendar.
