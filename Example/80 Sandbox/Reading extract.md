# Reading extract

Fictional prose for Highlightr, Note Refactor and search exercises. Work on a copy if you want to retain this starting point.

## Observation

Let a visitor describe a star field before offering its name. A quiet red lantern makes the printed chart easier to read without dominating the view. Ask what surprised them and record their own words.

## Teaching idea

A garden sign can use the same pattern: invite an observation, then supply a name. Visitors remember the seedling they noticed themselves.

## Try the editing tools

1. Highlight “record their own words” with Highlightr, then inspect the saved `<mark>` markup in Source mode. Compare with ==a native highlight==.
2. In another copy, select the Observation paragraph and use Note Refactor's extraction command. Choose a new note name, inspect the result and the source replacement/link, then follow it back.
3. Search for `quiet red lantern` with Omnisearch; this note and [[70 Data/Library/Watching the night sky]] give two meaningful contexts.

Extraction creates a note; it does not add Resource metadata or a flashcard automatically. Use the Resource fileClass selector or write a deliberate card in [[70 Data/Flashcards]] if that is the next step you want.
