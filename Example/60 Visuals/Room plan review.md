# Room plan review

The prepared [[60 Visuals/Workshop room.excalidraw|Excalidraw room plan]] contains a welcome desk, two grouped stations, a closing point and bound route arrows. Four boxes link to their actual source notes. Its Markdown drawing file uses uncompressed scene data so you can inspect the source.

![[60 Visuals/Workshop room.excalidraw]]

## Exercise 1 · Rearrange a station

Open a copy in Excalidraw, select the garden group and move it. Its label should move with the box; inspect the bound arrow connection too. Change a label, save and reopen the copy.

## Exercise 2 · Follow the source of a diagram element

Use the drawing's link-opening gesture on Telescope station and Seedling station. They point to Observatory and Garden. Welcome desk points to the visitor briefing; the closing point points to the decision register. Inspect those links in the drawing's element-link controls.

## Exercise 3 · Explain a decision in a meeting

Embed your drawing copy in a meeting note and keep the decision as text beside it. Edit the drawing and refresh the embed. Drawings provide context; moving a station does not modify the project's status or Kanban card.

## Exercise 4 · Share a stable view

Export SVG or PNG through Excalidraw and compare with the original SVG reference below. The shipped reference was generated from the same prepared scene; it is a static overview, not a runtime export receipt. Excalidraw's export settings can change padding, fonts and colors.
