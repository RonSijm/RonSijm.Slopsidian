# Example vault

This folder is the example Obsidian vault included in Slopsidian's repository.

In Obsidian, choose **Open folder as vault**, select **`Example`**, and open [Start here](Start%20here.md). In Slopsidian, select the same folder in the vault chooser.

The core examples use Obsidian's stock theme and built-in features. For the optional community examples, install the named plugins through **Settings → Community plugins → Browse**. Follow [the setup guide](00%20Start/Install%20community%20plugins.md); no build or terminal commands are needed.

| Location | What's inside |
| --- | --- |
| `Start here.md` | The starting note and a short route through the examples. |
| `00 Start` | The core and community tours, plugin setup, and sample-data notes. |
| `10 Core` | 31 guides to built-in workflows. |
| `20 Community` | 30 optional plugin guides, each with an exercise and expected result. |
| `30 Projects` | Four linked sample projects used by the task queries and Bases view. |
| `40 Journal` | A sample week of daily notes, plus weekly and monthly reviews. |
| `50 Templates` | Native Templates and optional Templater examples. |
| `60 Visuals` | A Canvas, Excalidraw sketch, Kanban board, and slides. |
| `70 Data` | A native Base, habit data, flashcards, and a word bank. |
| `80 Sandbox` | Notes to edit while trying the exercises. |
| `90 Attachments` | The sample SVG and generated audio tone. |
| `98 Archive` | An isolated note for the graph-view exercise. |
| `.obsidian` | Obsidian's vault settings, bookmarks, property types, and an optional CSS snippet. |
| `.gitignore` | Keeps local layouts, downloaded plugins, and cache files out of Git. |

Community plugins start disabled. Each guide records its reference version and minimum Obsidian version; the store may provide a newer release. The examples are a curated collection, and Slopsidian's plugin support may differ from Obsidian's.
