# Canvas

Open [[60 Visuals/Project constellation.canvas]]. Move a note card, connect two cards, add a text card, then close and reopen the canvas.

**Expected:** the cards, group and edges render, and your changes persist. The note cards open ordinary Markdown files. This example needs only the built-in Canvas plugin.
