# Editor status

Open [[80 Sandbox/Editing playground]]. Use the note menu to select **Source mode** and **Live Preview**, then toggle **Reading view** using **Ctrl+E** (macOS: **Cmd+E**). Inspect the editor-mode indicator when your version shows it.

**Expected:** the same file can be edited as Markdown or read as rendered content. Some Obsidian versions treat editor status as built-in UI rather than a separately visible Core plugins toggle.
