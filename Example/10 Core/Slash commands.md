# Slash commands

Open [[80 Sandbox/Editing playground]] in an editing mode. Start a new line, type `/`, and choose a command such as inserting a template.

**Expected:** a command menu appears in the editor. If it does not, check that Slash commands is enabled under Core plugins. Remove your test line when finished.
