# Daily notes

Use **Daily notes: Open today’s daily note**. The supplied settings use `40 Journal/Daily`, `YYYY-MM-DD`, and [[50 Templates/Core/Daily]].

**Expected:** today’s existing sample opens, or a new dated note is made from the template. The sample week is fixed at 19–25 October 2026; a new current-date note after that week is normal.
