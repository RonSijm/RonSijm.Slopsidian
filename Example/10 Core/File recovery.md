# File recovery

Open [[80 Sandbox/Recover this note]], edit and save a sentence, then wait at least the snapshot interval shown in File recovery settings. Edit and save it again; inspect the snapshots from File recovery settings.

**Expected:** an earlier saved version can be previewed and restored. Recovery history is local to your Obsidian installation and is intentionally absent from the repository.
