# Search

Open Search and try these queries separately:

- `path:"30 Projects"`
- `tag:#project/active`
- `spectroheliograph`
- `path:"30 Projects" [status:active]`

**Expected:** the word search includes [[80 Sandbox/Search target]]. Click a result to jump to its context. Use the path filter to keep project results focused on the fixtures.
