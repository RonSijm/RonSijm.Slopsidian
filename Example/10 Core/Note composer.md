# Note composer

Open [[80 Sandbox/Compose source]]. Select the paragraph under “Extract this”, then use Note composer’s extract command. Choose a new sandbox note. Try merging a copy of the source into [[80 Sandbox/Compose target]].

**Expected:** the selected text moves into the destination and a link can replace it. Work on copies if you want to preserve the original exercises.
