# Templates

Create a new note in `80 Sandbox`. Run **Templates: Insert template** and choose [[50 Templates/Core/Note]].

**Expected:** the title, date and time placeholders are replaced. The template folder is `50 Templates/Core`. Templater has a separate folder and guide so its syntax never appears in this core workflow.
