# Files

Open [[30 Projects/Observatory]]. In the file explorer, create a note inside `80 Sandbox`, rename it, then move it to another sandbox folder.

**Expected:** the tree follows your changes and the note reopens with its content intact. Try the folder context menu as well as the note menu.
