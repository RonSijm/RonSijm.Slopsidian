# Unique note creator

Run **Unique note creator: Create new unique note**. Settings point to `80 Sandbox` and [[50 Templates/Core/Unique]].

**Expected:** a timestamp-named note is created without replacing an existing note. Its body includes the date and a place to write one durable idea.
