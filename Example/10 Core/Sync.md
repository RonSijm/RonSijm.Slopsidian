# Sync

If you have an Obsidian Sync subscription, connect a disposable copy of this vault to your own remote vault and open it on a second device. Change a sandbox note and check the other device.

**Expected:** your configured service transfers the change. A Git clone is a separate copy; Git alone does not supply Obsidian Sync, live merging, or a Sync subscription.
