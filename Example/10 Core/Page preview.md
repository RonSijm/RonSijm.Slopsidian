# Page preview

Hold **Ctrl** (macOS: **Cmd**) while hovering over [[30 Projects/Observatory]], then over [[30 Projects/Observatory#Next actions]]. Preview behavior can be configured per context in Page preview settings.

**Expected:** a preview appears without navigating away. Try again from Reading view and from a link in the Backlinks pane.
