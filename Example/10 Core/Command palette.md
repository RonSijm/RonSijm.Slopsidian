# Command palette

Press **Ctrl+P** (macOS: **Cmd+P**). Search for `daily`, `template`, `graph`, and `workspace` in turn. Run **Outline: Show outline** while this note is active.

**Expected:** available core commands appear with their assigned shortcuts. Community commands are added when their individual plugins are enabled.
