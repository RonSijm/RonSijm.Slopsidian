# Web viewer

On desktop, enable Web viewer and open [Obsidian Help](https://help.obsidian.md) inside the app using the link menu or Web viewer’s command. Navigate, go back, and search within the page.

**Expected:** an embedded browser opens the public documentation. This workflow needs network access and is not available in every mobile or browser-hosted vault editor.
