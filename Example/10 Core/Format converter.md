# Format converter

Inspect [[80 Sandbox/Format conversion]]. In Obsidian versions that include Format converter, copy the fixture and run the converter on the copy.

**Expected:** supported legacy notation is converted to native Markdown. This is a legacy core workflow: newer Obsidian releases may direct you to the separate Importer plugin instead. The original fixture remains readable without either tool.
