# Graph view

Open **Graph view: Open graph view** from the command palette. Filter to `path:"30 Projects"` and open a project node. Open the local graph for [[30 Projects/Observatory]] and increase its depth.

**Expected:** related project and meeting notes form a connected cluster. The deliberately unlinked `98 Archive/Isolated thought.md` can be inspected with the orphan-node option.
