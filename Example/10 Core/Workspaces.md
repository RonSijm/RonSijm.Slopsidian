# Workspaces

Arrange [[30 Projects/Observatory]] beside [[70 Data/Projects.base]], with Outline visible. Use **Workspaces: Manage workspace layouts** to save the layout as “Project review”. Change the layout, then load it again.

**Expected:** the saved panes return. This vault does not ship personal window coordinates or a machine-specific workspace file.
