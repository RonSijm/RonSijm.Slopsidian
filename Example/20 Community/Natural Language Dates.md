# Natural Language Dates

> [!info] Optional plugin
> Install and enable **Natural Language Dates** (`nldates-obsidian`) for this exercise. Reference version: **0.6.4**. Minimum Obsidian: **1.0.0**. See [[00 Start/Install community plugins]].

Open [[80 Sandbox/Editing playground#Date capture]]. Put the cursor after the prompt, type `@tomorrow`, and choose the suggested date. You can also select `next Friday` and use the plugin’s date-parsing command.

**Expected:** a date link is inserted using your configured format. Its value depends on today and locale. Set the date format to `YYYY-MM-DD` to match the supplied daily notes.
