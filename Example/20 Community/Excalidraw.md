# Excalidraw

> [!info] Optional plugin
> Install and enable **Excalidraw** (`obsidian-excalidraw-plugin`) for this exercise. Reference version: **2.29.0**. Minimum Obsidian: **1.8.7**. See [[00 Start/Install community plugins]].

Open [[60 Visuals/Sketch.excalidraw]]. This is an uncompressed drawing in Excalidraw’s legacy JSON format; the plugin supports opening it, and its conversion command can create a modern drawing note.

Move the two boxes, draw an arrow and reopen the file. You can also use Excalidraw’s new-drawing command to create a modern `.excalidraw.md` note.

**Expected:** the sketch is editable and the edit persists. [[60 Visuals/Project constellation.canvas]] is the native alternative; [[90 Attachments/Vault map.svg]] supplies an always-readable overview.
