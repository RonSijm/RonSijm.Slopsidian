# Excalidraw

> [!info] Included plugin — enable it to try this
> Enable the included **Excalidraw** (`obsidian-excalidraw-plugin`) for this exercise. Reference version: **2.29.0**. Minimum Obsidian: **1.8.7**. See [[00 Start/Install community plugins]].

The prepared [[60 Visuals/Workshop room.excalidraw|room drawing]] is a modern Markdown drawing with 16 elements: four linked activity boxes, grouped labels, bound route arrows and a locked room outline. [[60 Visuals/Room plan review]] embeds it beside an original static SVG reference.

## Rearrange and save a real plan

Open a copy, move the garden group and inspect its label and connected route. Change the welcome wording, save and reopen it. Grouping keeps the station's parts together; arrow bindings describe the relationships between boxes.

**Expected:** your copy retains the changed scene. The prepared SVG remains a separate reference and does not automatically regenerate.

## Navigate from the drawing to its sources

Open the links on Telescope station, Seedling station, Welcome desk and the closing point using Excalidraw's link gesture or element-link action. They lead to Observatory, Garden, Visitor briefing and the Decision register. A box is a navigational entry into real notes, not a duplicate project record.

## Embed and export a view

Embed a drawing copy in a meeting note, describe one decision beside it, and change the drawing to compare the refreshed embed. Export SVG or PNG through the plugin. The lab explains which parts are saved scene data, editable note links and static exports.

[[60 Visuals/Workshop room (portable).excalidraw]] is an independent plain JSON scene for compatible tools. [[60 Visuals/Sketch.excalidraw]] remains the smaller legacy-format exercise; the plugin's conversion command can create a modern note from it. Avoid using a modern and legacy file with the same exact link target.

Remove practice copies and exports to reset. This lab uses local drawing data and native font family 2; it does not require AI generation, downloaded scripts, OCR or an external image service.
