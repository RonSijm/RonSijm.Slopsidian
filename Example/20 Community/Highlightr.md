# Highlightr

> [!info] Optional plugin
> Install and enable **Highlightr** (`highlightr-plugin`) for this exercise. Reference version: **1.2.2**. Minimum Obsidian: **0.12.8**. See [[00 Start/Install community plugins]].

Open [[80 Sandbox/Editing playground#Highlights]]. Select “Make this sentence easy to find” and use Highlightr’s menu or command to choose a color.

**Expected:** the sentence gains colored highlight markup. Compare it with the supplied native `==highlight==`. Inspect Source mode to see how the plugin stores the color.
