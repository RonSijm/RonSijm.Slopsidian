# Recent Files

> [!info] Included plugin — enable it to try this
> Enable the included **Recent Files** (`recent-files-obsidian`) for this exercise. Reference version: **1.7.10**. Minimum Obsidian: **0.16.3**. See [[00 Start/Install community plugins]].

[[80 Sandbox/Plugin lab/Navigation desk]] supplies three prepared work routes. Recent Files uses the visits you actually make; no synthetic history is written into your settings.

## Resume a chain of work

Follow Route A: cockpit → delivery board → visitor briefing → planning meeting. Return to Navigation desk, open the Recent Files sidebar and reopen the briefing. Repeat Route B to build a different research chain.

**Expected:** the order reflects your visits. Reopening a resource does not mark it read, and returning to a project does not toggle its review property.

## Reuse a recent item in another context

Ctrl/Cmd-click an entry to open it in another pane. Drag an entry into a scratch editor to insert a link, or onto a pane header to open it there. Inspect the inserted link's actual destination. Use copies when exploring drag targets: dragging onto an explorer folder can move a file.

## Preview before reopening

With core Page preview enabled and its Recent Files toggle selected, hover or modifier-hover according to your settings. Compare the preview with opening the file. This is useful when the same research route contains a source, extract and meeting note with similar wording.

## Keep session noise out of the list

Try a temporary omitted path for `50 Templates` or a frontmatter-tag exclusion in Recent Files settings. Open a matching note and an ordinary note, then compare. Remove the test exclusion to restore your preferences. Exclusion changes the recent list; the file stays in the vault.

This update leaves your existing history untouched. History changes naturally as you perform the exercises.
