# Recent Files

> [!info] Optional plugin
> Install and enable **Recent Files** (`recent-files-obsidian`) for this exercise. Reference version: **1.7.10**. Minimum Obsidian: **0.16.3**. See [[00 Start/Install community plugins]].

Open [[30 Projects/Observatory]], [[30 Projects/Garden]] and [[40 Journal/Daily/2026-10-23]] in that order. Select the Recent Files tab in the sidebar.

**Expected:** the recently visited notes appear and clicking one reopens it. Your visit history is created locally; the repository ships no personal history.
