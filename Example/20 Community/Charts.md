# Charts

> [!info] Optional plugin
> Install and enable **Charts** (`obsidian-charts`) for this exercise. Reference version: **3.9.0**. Minimum Obsidian: **0.12.7**. See [[00 Start/Install community plugins]].

This chart uses local, synthetic values. Open Reading view.

```chart
type: bar
labels: [Mon, Tue, Wed, Thu, Fri, Sat, Sun]
series:
  - title: Focus sessions
    data: [2, 3, 1, 4, 3, 2, 1]
width: 80%
beginAtZero: true
```

**Expected:** seven bars. Edit Wednesday’s value and compare. The values are example data, not an external feed. [[70 Data/Habit data]] provides a plain table.
