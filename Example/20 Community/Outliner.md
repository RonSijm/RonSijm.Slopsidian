# Outliner

> [!info] Optional plugin
> Install and enable **Outliner** (`obsidian-outliner`) for this exercise. Reference version: **4.10.2**. Minimum Obsidian: **1.11.7**. See [[00 Start/Install community plugins]].

Open [[80 Sandbox/Editing playground#Outline exercise]] in an editing mode. Fold “Plan the visit”, indent one child, and use Outliner’s move-list-item commands to reorder the children.

**Expected:** the parent/child structure stays intact while complete list items move. Fold state and controls depend on your Outliner settings.
