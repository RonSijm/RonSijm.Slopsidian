# Iconize

> [!info] Optional plugin
> Install and enable **Iconize** (`obsidian-icon-folder`) for this exercise. Reference version: **2.14.7**. Minimum Obsidian: **0.9.12**. See [[00 Start/Install community plugins]].

In the file explorer, use Iconize’s context-menu action on `30 Projects` and pick an available built-in icon. Repeat for [[30 Projects/Observatory]].

**Expected:** icons appear beside the folder and note. If the chosen icon pack needs a download, install that pack through Iconize’s settings. The underlying names and links remain ordinary vault paths.
