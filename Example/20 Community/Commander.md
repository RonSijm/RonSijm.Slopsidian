# Commander

> [!info] Optional plugin
> Install and enable **Commander** (`cmdr`) for this exercise. Reference version: **0.7.0**. Minimum Obsidian: **1.13.0**. See [[00 Start/Install community plugins]].

In Commander settings add a ribbon or tab-bar button for **Daily notes: Open today’s daily note**. Choose a calendar icon and a label you recognize.

**Expected:** clicking the new button opens the same day note as the core command palette action. Remove the button from Commander settings when finished. No custom macro is needed.
