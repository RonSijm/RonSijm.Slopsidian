# Omnisearch

> [!info] Optional plugin
> Install and enable **Omnisearch** (`omnisearch`) for this exercise. Reference version: **1.31.0**. Minimum Obsidian: **1.13.3**. See [[00 Start/Install community plugins]].

Open Omnisearch’s vault search from the command palette or its search ribbon button and look for `spectroheliograph`. Open the result in [[80 Sandbox/Search target]]. Then search `Sky lab` to try a project alias.

**Expected:** the fixture is found and opens at useful context. This demo covers Markdown search; it does not require OCR, a PDF helper, or extra services. Compare with native [[10 Core/Search]].
