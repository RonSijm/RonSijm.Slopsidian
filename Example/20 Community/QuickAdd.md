# QuickAdd

> [!info] Optional plugin
> Install and enable **QuickAdd** (`quickadd`) for this exercise. Reference version: **2.32.1**. Minimum Obsidian: **1.13.0**. See [[00 Start/Install community plugins]].

In QuickAdd settings, create a **Capture** choice called `Demo inbox`. Set Capture To to `80 Sandbox/Capture inbox.md` and Capture format to `- {{DATE:HH:mm}} {{VALUE}}`. Use the end-of-file write position.

Run **QuickAdd: Run**, choose Demo inbox, and enter `Remember the star charts`.

**Expected:** one timestamped line is appended to [[80 Sandbox/Capture inbox]]. The recipe uses neither macros nor external APIs. This configuration is intentionally manual so you can see what a capture choice does.
