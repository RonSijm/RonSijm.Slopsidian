# Advanced Tables

> [!info] Optional plugin
> Install and enable **Advanced Tables** (`table-editor-obsidian`) for this exercise. Reference version: **0.23.2**. Minimum Obsidian: **1.0.0**. See [[00 Start/Install community plugins]].

Open [[80 Sandbox/Editing playground#Tables]] in Source mode. Put the cursor in a table cell and press Tab; press Enter at the end of the last row. Try the table toolbar’s alignment controls.

**Expected:** the cursor moves through cells and the plugin maintains the Markdown table. Native Obsidian still displays and edits the table when the plugin is disabled.
