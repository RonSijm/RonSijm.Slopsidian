# Admonition

> [!info] Optional plugin
> Install and enable **Admonition** (`obsidian-admonition`) for this exercise. Reference version: **12.0.11**. Minimum Obsidian: **1.13.0**. See [[00 Start/Install community plugins]].

Compare the native callout with the plugin block in Reading view.

> [!tip] Native callout
> This works without a community plugin.

```ad-tip
title: Plugin admonition
This separate block is rendered by the Admonition plugin.
```

**Expected:** both appear as styled notices with Admonition enabled. The native callout stays useful when the plugin is disabled.
