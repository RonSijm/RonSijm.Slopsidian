# Tasks

> [!info] Optional plugin
> Install and enable **Tasks** (`obsidian-tasks-plugin`) for this exercise. Reference version: **8.6.0**. Minimum Obsidian: **1.13.1**. See [[00 Start/Install community plugins]].

Open Reading view after enabling Tasks. No global task filter is needed for this query.

```tasks
not done
path includes 30 Projects/
sort by description
```

**Expected:** five unfinished project tasks at the sample baseline. Tick one result and inspect its source note. Dates in this vault are fixed demo dates, so due/overdue status changes with the calendar.
