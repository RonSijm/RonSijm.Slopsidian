# Linter

> [!info] Optional plugin
> Install and enable **Linter** (`obsidian-linter`) for this exercise. Reference version: **1.34.2**. Minimum Obsidian: **1.13.0**. See [[00 Start/Install community plugins]].

Open a copy of [[80 Sandbox/Lint me]]. In Linter settings enable the heading-blank-line rule and a trailing-space cleanup rule. Keep lint-on-save disabled while exploring.

Run **Linter: Lint the current file** and inspect the changes.

**Expected:** spacing is normalized while sentences remain intact. Use Undo to compare. Avoid a whole-vault lint until you have chosen your preferred rules.
