# Kanban

> [!info] Included plugin — enable it to try this
> Enable the included **Kanban** (`obsidian-kanban`) for this exercise. Reference version: **2.0.51**. Minimum Obsidian: **1.0.0**. See [[00 Start/Install community plugins]].

[[60 Visuals/Workshop delivery board]] is a populated four-lane preparation board with eight cards, linked source notes, topic tags and six fixed dates. [[60 Visuals/Project board]] remains the smaller three-column example.

## Move the work through a preparation conversation

Open a copy as a Kanban board. Move Print the seedling labels from Ready to Doing, reorder it relative to another card, and edit its wording. Follow its Sign wording link to inspect the actual material.

**Expected:** list membership, card order and text change in the board's Markdown. They do not set `status` on Garden or complete a task in the project note.

## Find a station's cards

Use the board's search/filter controls with `welcome`, `logistics` or `station/garden`. Inspect the cards' tags and compare that focused view with the whole board. The cards deliberately include both an activity label and a source link so a filtered plan retains context.

## Review and change a date

Open a card's date control and compare it with Source mode's `@{2026-11-12}` marker. Change the date in your copy, save and reopen it. The board uses `YYYY-MM-DD`; these fixed example dates can appear overdue as the real calendar advances.

## Finish and archive deliberately

Check a practice card, inspect its checkbox in Markdown, then try the plugin's archive-completed-cards action on the board copy. Compare the live lanes with the stored archived content. A card in the Done lane and a checked card are separate aspects of the board.

Return cards to their original lanes/dates or delete the copy to reset. The sample keeps all task/project/card values independent so you can see exactly what each operation writes.
