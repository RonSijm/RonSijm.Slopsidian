# Kanban

> [!info] Optional plugin
> Install and enable **Kanban** (`obsidian-kanban`) for this exercise. Reference version: **2.0.51**. Minimum Obsidian: **1.0.0**. See [[00 Start/Install community plugins]].

Open [[60 Visuals/Project board]]. Use the note menu’s board/Markdown toggle if the board does not open automatically.

Move “Choose a telescope” from Backlog to In progress and add a new card.

**Expected:** a three-column board appears, and dragging a card updates the underlying Markdown. With Kanban disabled, the same file is a readable list of headings and checkboxes.
