# Homepage

> [!info] Optional plugin
> Install and enable **Homepage** (`homepage`) for this exercise. Reference version: **4.5.0**. Minimum Obsidian: **1.13.0**. See [[00 Start/Install community plugins]].

In Homepage settings choose **File** and select `Start here.md` as the homepage. Enable opening it on startup if you want that behavior. Run the plugin’s open-homepage command.

**Expected:** [[Start here]] opens. Reopen the vault to try the startup option. The core experience also has a Start here bookmark, so a homepage plugin is optional.
