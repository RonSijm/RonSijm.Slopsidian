# Periodic Notes

> [!info] Optional plugin
> Install and enable **Periodic Notes** (`periodic-notes`) for this exercise. Reference version: **0.0.17**. Minimum Obsidian: **0.10.11**. See [[00 Start/Install community plugins]].

In Periodic Notes settings, enable weekly and monthly notes. Configure weekly folder `40 Journal/Weekly`, format `GGGG-[W]WW`, template [[50 Templates/Core/Weekly]]; monthly folder `40 Journal/Monthly`, format `YYYY-MM`, template [[50 Templates/Core/Monthly]].

Run the plugin’s open weekly and open monthly commands.

**Expected:** it opens or creates the current period’s note. Fixed fixtures [[40 Journal/Weekly/2026-W43]] and [[40 Journal/Monthly/2026-10]] show the intended format regardless of today’s date.
