# Calendar

> [!info] Optional plugin
> Install and enable **Calendar** (`calendar`) for this exercise. Reference version: **1.5.10**. Minimum Obsidian: **0.9.11**. See [[00 Start/Install community plugins]].

Install Calendar from Obsidian's plugin browser. Run its open-calendar command and navigate to **October 2026**. Daily notes use `40 Journal/Daily` and `YYYY-MM-DD`.

Click 23 October, then another day in the sample week.

**Expected:** [[40 Journal/Daily/2026-10-23]] and the matching day notes open. A day outside that week can create a new note after confirmation. This guide uses Calendar’s registered stable ID, not the separate beta ID.
