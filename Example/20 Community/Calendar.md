# Calendar

> [!info] Included plugin — enable it to try this
> Enable the included **Calendar** (`calendar`) for this exercise. Reference version: **1.5.10**. Minimum Obsidian: **0.9.11**. See [[00 Start/Install community plugins]].

Daily note settings already use `40 Journal/Daily`, `YYYY-MM-DD` and [[50 Templates/Core/Daily]]. Calendar's weekly note display is enabled and matches the Periodic Notes weekly folder, format and template.

## Navigate an existing week

Run Calendar's open-calendar command and navigate to **October 2026**. Click day **23**, then another day from 19–25 October.

**Expected:** [[40 Journal/Daily/2026-10-23]] and the other supplied daily notes open. Dots reflect note content according to Calendar's word-count settings; they are not the sleep or mood measurements.

## Open a weekly review

With Periodic Notes enabled, use the calendar's week-number entry for ISO week 43. It opens [[40 Journal/Weekly/2026-W43]]. Weekly format is `GGGG-[W]WW`, preserving the ISO week-year near New Year.

Try a missing day in a disposable copy. Calendar asks before creating it and uses the configured daily-note template. Its date depends on the selected day, whereas QuickAdd's daily capture choice uses today's date. Keep the original seven journal records for the fixed-range chart exercise.

Calendar navigates notes; it does not automatically set numeric habits, task due dates or a project's review flag. This guide uses Calendar's stable registered ID, not its separate beta package.
