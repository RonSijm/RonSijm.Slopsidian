# Checklist

> [!info] Optional plugin
> Install and enable **Checklist** (`obsidian-checklist-plugin`) for this exercise. Reference version: **3.1.0**. Minimum Obsidian: **1.5.0**. See [[00 Start/Install community plugins]].

In **Settings → Checklist**, set **Included tags** to `todo` (the plugin accepts it with or without `#`). Run **Checklist: Show Checklist pane** from the command palette.

**Expected:** the three unchecked items in the `#todo` block in [[80 Sandbox/Checklist fixture]] appear. Check one in the pane and inspect its source. The tag is immediately above its tasks; a blank line ends a standalone tagged block. This example is separate from Tasks queries.
