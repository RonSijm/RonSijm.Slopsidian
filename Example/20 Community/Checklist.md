# Checklist

> [!info] Additional plugin — not installed
> Install and enable **Checklist** (`obsidian-checklist-plugin`) for this exercise. Reference version: **3.1.0**. Minimum Obsidian: **1.5.0**. See [[00 Start/Install community plugins]].

This package is **not included**; install it separately in Obsidian. Set **Included tags** in Checklist settings to `todo` (accepted with or without `#`), then run **Checklist: Show Checklist pane**.

## Collect the packing list

[[80 Sandbox/Checklist fixture]] has three unchecked items in its `#todo` block. Check one through the pane and inspect its source checkbox, then Undo. A standalone tag belongs immediately above its tasks; a blank line ends the tagged block.

## Keep a small operational list separate

In a copy of that fixture, replace the sample items with workshop packing steps such as bringing labels and printing the welcome sign. The tag collects them without making them Project class records or adding them to the cockpit's Projects-path Tasks query.

**Expected:** the pane collects the included tagged tasks. This is a separate plugin from Tasks: a matching tag is its inclusion rule, while the cockpit uses an explicit source path. Remove your copy to reset.
