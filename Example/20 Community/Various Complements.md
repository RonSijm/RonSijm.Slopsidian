# Various Complements

> [!info] Optional plugin
> Install and enable **Various Complements** (`various-complements`) for this exercise. Reference version: **11.4.2**. Minimum Obsidian: **1.11.4**. See [[00 Start/Install community plugins]].

Open [[70 Data/Word bank]] once so the plugin can index its vocabulary. In plugin settings enable completion from the current vault. In [[80 Sandbox/Editing playground#Completion exercise]], type `constell` and choose a suggestion.

**Expected:** a suggestion such as `constellation` can complete the word. Thresholds and triggering differ with plugin settings; the sample word bank provides repeated terms.
