# Spaced Repetition

> [!info] Additional plugin — not installed
> Install and enable **Spaced Repetition** (`obsidian-spaced-repetition`) for this exercise. Reference version: **1.15.4**. Minimum Obsidian: **1.2.8**. See [[00 Start/Install community plugins]].

This package is **not included**; install it separately in Obsidian. [[70 Data/Flashcards]] has the `flashcards` tag and three simple astronomy question/answer cards. Select that tag as a flashcard tag in the plugin's settings.

## Review a tiny deck

Start a flashcard review from the plugin command. Reveal an answer and grade it. Inspect Source mode afterwards: scheduling information is written locally, so another review can have different due cards.

## Turn a reading idea into one deliberate card

In a copy of the deck, add a single-line card such as `What should a visitor do before hearing the star's name?::Describe what they notice.` It comes from [[80 Sandbox/Reading extract]]. Review that deck and check the new prompt appears.

**Expected:** review practice for a small explicit set of cards. A colored highlight or Resource class does not create a card automatically. Keep questions narrow enough to judge your answer; the synthetic astronomy facts are teaching examples. Use a disposable copy if you want to keep the original deck free of review history.
