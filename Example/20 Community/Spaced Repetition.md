# Spaced Repetition

> [!info] Optional plugin
> Install and enable **Spaced Repetition** (`obsidian-spaced-repetition`) for this exercise. Reference version: **1.15.4**. Minimum Obsidian: **1.2.8**. See [[00 Start/Install community plugins]].

Open [[70 Data/Flashcards]], which carries the `flashcards` tag. Make sure that tag is selected as a flashcard tag in Spaced Repetition settings. Start a flashcard review from the plugin command.

**Expected:** three simple question/answer cards appear. Reveal an answer and grade it; the plugin writes scheduling information to your local notes. A fresh clone has no review history.
