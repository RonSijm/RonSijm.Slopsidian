# Templater

> [!info] Optional plugin
> Install and enable **Templater** (`templater-obsidian`) for this exercise. Reference version: **2.26.0**. Minimum Obsidian: **1.13.0**. See [[00 Start/Install community plugins]].

In Templater settings, set **Template folder location** to `50 Templates/Templater`. Leave automatic file triggers and system commands disabled for this exercise.

1. Create a new sandbox note called `My demo project`.
2. Run **Templater: Open insert template modal** and choose [[50 Templates/Templater/Project]].
3. Enter a sentence at the inserted cursor position.

**Expected:** the new note’s title and today’s date replace the template expressions. Core Templates uses its own separate template folder.
