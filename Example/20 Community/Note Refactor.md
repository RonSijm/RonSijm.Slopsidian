# Note Refactor

> [!info] Optional plugin
> Install and enable **Note Refactor** (`note-refactor-obsidian`) for this exercise. Reference version: **1.8.2**. Minimum Obsidian: **not declared by upstream**. See [[00 Start/Install community plugins]].

Open a copy of [[80 Sandbox/Refactor playground]]. Select the paragraph under “Observation” and use Note Refactor’s extract-selection command. Try splitting the copy by headings as a second exercise.

**Expected:** new Markdown notes contain the selected sections and can be linked from the source. Compare the core [[10 Core/Note composer]] workflow.
