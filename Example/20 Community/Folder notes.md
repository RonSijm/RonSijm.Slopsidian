# Folder notes

> [!info] Optional plugin
> Install and enable **Folder notes** (`folder-notes`) for this exercise. Reference version: **1.8.26**. Minimum Obsidian: **1.4.10**. See [[00 Start/Install community plugins]].

The folder note [[30 Projects/30 Projects]] has the same name as its containing folder. Configure Folder notes to keep a folder note **inside** its folder and use the folder’s name.

Click the Projects folder using the plugin’s folder-opening gesture (depending on settings, click or modifier-click).

**Expected:** the project index opens. It remains an ordinary, clickable Markdown note with the plugin disabled.
