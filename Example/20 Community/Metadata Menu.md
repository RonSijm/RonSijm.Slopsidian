# Metadata Menu

> [!info] Optional plugin
> Install and enable **Metadata Menu** (`metadata-menu`) for this exercise. Reference version: **0.8.12**. Minimum Obsidian: **1.4.16**. See [[00 Start/Install community plugins]].

Enable Dataview as well as Metadata Menu for the broader metadata workflows. Open [[30 Projects/Observatory]], then use Metadata Menu’s file-menu/ribbon action to inspect its fields.

Change `priority` from `high` to `medium`, reopen the note source, then restore it.

**Expected:** the existing field changes without losing `hours`, `tags` or the note body. Define a field called `priority` with selectable values `low`, `medium`, `high` in plugin settings to try a constrained editor. Native Properties supplies the baseline editor.
