# Git

> [!info] Optional plugin
> Install and enable **Git** (`obsidian-git`) for this exercise. Reference version: **2.42.0**. Minimum Obsidian: **1.13.0**. See [[00 Start/Install community plugins]].

This `Example` folder is already inside Slopsidian's Git repository. Use that existing repository for the exercise. Desktop Git must be installed; mobile behavior differs.

Change a sandbox note and inspect its diff in the Git plugin's source-control view.

**Expected:** the changed example appears in the existing repository's working tree. Keep automatic commit and push disabled while exploring.
