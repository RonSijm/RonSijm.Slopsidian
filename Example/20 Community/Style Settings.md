# Style Settings

> [!info] Optional plugin
> Install and enable **Style Settings** (`obsidian-style-settings`) for this exercise. Reference version: **1.0.9**. Minimum Obsidian: **0.11.5**. See [[00 Start/Install community plugins]].

In **Appearance → CSS snippets**, enable `demo-style-settings`, then open Style Settings and find **Example vault accents**. Change the callout radius or accent color and inspect the callout below.

> [!example] A local style experiment
> Only this optional snippet changes the stock presentation.

**Expected:** the controls affect the demo styling. The snippet is shipped disabled, and no community theme is needed. Turn it off to return to stock appearance.
