# Style Settings

> [!info] Additional plugin — not installed
> Install and enable **Style Settings** (`obsidian-style-settings`) for this exercise. Reference version: **1.0.9**. Minimum Obsidian: **0.11.5**. See [[00 Start/Install community plugins]].

This package is **not included**; install it separately in Obsidian. In **Appearance → CSS snippets**, enable `demo-style-settings`, then find **Example vault accents** in Style Settings.

## Make a planning notice easy to recognize

Change the accent color and callout radius, then compare this callout and the planning notice in [[80 Sandbox/Workshop agenda]]. Inspect the supplied snippet's settings declaration if you want to see how CSS exposes controls to the plugin.

> [!example] A local style experiment
> The optional snippet supplies the actual styling; Style Settings supplies its controls.

**Expected:** the selected controls change the snippet's styled elements. They do not rewrite project properties or assign explorer icons. No community theme is required. Turn off `demo-style-settings` to return to the stock appearance; it starts disabled.
