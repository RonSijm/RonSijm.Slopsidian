# Community tour

A curated collection of **30 community plugins**, with a real fixture or a reproducible workflow for each. This is an expandable sampler, not a claim to include the thousands of plugins in Obsidian’s registry.

Start with Dataview, Tasks, Templater, Kanban and Excalidraw. Enable a few at a time; many others demonstrate commands and editor actions rather than a dashboard.
