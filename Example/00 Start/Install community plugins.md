# Install community plugins

The [[00 Start/Core tour|core tour]] works with community plugins disabled. The [[00 Start/Community tour|community tour]] contains optional exercises for 30 plugins.

1. Open this `Example` folder as an Obsidian vault.
2. Open **Settings → Community plugins** and turn off Restricted mode if you want to use community plugins.
3. Choose **Browse**, search for a plugin named in the community tour, then install and enable it.
4. Open its guide and follow the setup steps and exercise. Start with a few plugins rather than enabling the whole collection at once.

Each guide lists the version used as a reference and that version's minimum Obsidian requirement. The plugin browser may offer a newer release with different requirements or controls.

Some examples need additional setup:

- [[20 Community/Templater]] uses `50 Templates/Templater` as its template folder. Native Templates uses the separate `50 Templates/Core` folder.
- [[20 Community/Periodic Notes]] explains the weekly and monthly folders, formats, and templates.
- [[20 Community/Metadata Menu]] uses Dataview for its broader metadata workflows.
- [[20 Community/Style Settings]] uses the optional `demo-style-settings` snippet, which starts disabled.
- [[20 Community/Git]] uses the existing repository and needs desktop Git installed.

If a query remains a code block, check that its plugin is enabled and switch to Reading view. Dataview and Bases initially show four projects; Tracker reads the fixed 19–25 October 2026 journal entries.

Install plugins through Obsidian before trying their examples in Slopsidian. Available workflows depend on Slopsidian's current plugin support.
