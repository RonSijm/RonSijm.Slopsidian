# Core tour

These 31 guides cover the core-module snapshot used by Slopsidian, including built-in editor status and the legacy Format converter. Current Obsidian may expose those two differently. The vault uses the stock theme; ordinary core modules are enabled for the tour. Publish and Sync are optional service exercises and remain disabled.

Start with Files, Quick switcher, Properties, Canvas and Bases. Guides give an action and an expected result.
