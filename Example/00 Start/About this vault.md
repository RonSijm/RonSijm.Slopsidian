# About this vault

`Example` is a vault within Slopsidian's repository. Its `.obsidian` folder contains native vault settings and 24 installed community plugin packages: the stock theme, Live Preview, a sandbox for new notes, an attachment folder, bookmarks, and template locations. WASM GitHub mounts load configured plugins automatically by default; an explicit Restricted mode choice is remembered locally. Desktop GitHub mounts still start in Restricted mode.

## Examples

The [[00 Start/Core tour|31 core guides]] cover built-in workflows, including editor status and the version-dependent legacy Format converter. The [[00 Start/Community tour|30 community guides]] have plugin setup steps, exercises, and expected results. Each community guide records its reference version and minimum Obsidian version.

Publish and Sync require your own Obsidian services, audio recording requires a microphone, and Web viewer needs desktop support and network access. Opening the vault in Slopsidian does not establish that every plugin workflow is supported there.

## Sample data

The people, projects, work items, and journal values are fictional. Journal entries use the fixed week **19–25 October 2026**, so Tracker has repeatable data. Commands that create today's note use your actual current date.

The original sample contains:

- Four projects, two of them active.
- Five unfinished project tasks and 16 remaining project hours.
- Seven daily sleep observations.
- A generated audio tone and original drawing, Canvas, and SVG examples.

`A future idea` in [[80 Sandbox/Link playground]] is deliberately unresolved. `98 Archive/Isolated thought.md` starts without incoming or outgoing links for the graph-view exercise.

## Local changes

The exercises change notes in a writable local copy. GitHub mounts keep remote notes read-only and save preferences locally. Use the existing repository's Git diff to inspect local changes and restore only the examples you want to reset. The local `.gitignore` excludes personal layouts, themes, caches, and the generated Git authentication helper; installed plugin packages are included.
