# Growing a shared garden

A fictional article for the garden station. It supplies a second record for class tables and grouped queries.

## Reading notes

Make each sign answer one visitor question. A drawing of the seedling is easier to match with a real plant than a long paragraph alone.

## Try a linked field

Open Metadata Menu's `project` editor. Its choices come from the four project records, so a person, dashboard or meeting should not appear as a project choice. Keep [[30 Projects/Garden]] selected.
